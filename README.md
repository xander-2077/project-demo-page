# 遥操入口页面

Claude 风格的纯静态前端，展示 G1、H1、H2、R1 四个机器人系列。无需安装依赖。

在仓库根目录启动：

```bash
python3 -m http.server 8080 --bind 127.0.0.1 --directory frontend
```

浏览器访问 **http://127.0.0.1:8080**，也可以直接打开 `frontend/index.html`。

- 四张机器人入口卡片，包含风格化 SVG 插画。
- 按机器人名称、型号或标签搜索，快捷键 `/`。
- 点击「进入遥操」查看型号并选择，最近选择保存到当前浏览器。
- 支持移动端导航、键盘操作及系统减少动画设置。
- 页面仅作展示，不连接机器人，不打开终端，不执行脚本。插画不是设备技术模型。

`index.html` 为页面结构，`styles.css` 为样式，`app.js` 为机器人目录与交互逻辑。后续可在 `openRobot()` 或型号选择事件中接入实际业务。
